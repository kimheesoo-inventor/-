# CLAUDE.md 작성 가이드

클로드 코드에서 AI가 내 의도대로 일관성 있게 움직이게 하는 가장 확실한 방법은
`CLAUDE.md`를 제대로 써 두는 것입니다. AI를 위한 **업무 매뉴얼이자 사규**라고 보면 됩니다.

---

## 0. 먼저: 파일명은 대문자 `CLAUDE.md`

Claude Code가 세션 시작 시 자동으로 읽는 파일명은 **대문자 `CLAUDE.md`** 입니다.
`claude.md`(소문자)로 만들면 대소문자를 구분하는 환경(리눅스·CI)에서 로드되지 않습니다.

읽히는 위치는 세 군데이고, 아래로 갈수록 우선합니다.

| 위치 | 적용 범위 | 용도 |
|------|-----------|------|
| `~/.claude/CLAUDE.md` | 내 모든 프로젝트 | 개인 공통 습관·톤 |
| `<프로젝트 루트>/CLAUDE.md` | 이 프로젝트 (팀 공유) | 프로젝트 규칙 — **여기가 기본** |
| `<하위 폴더>/CLAUDE.md` | 그 폴더 작업 시 | 폴더별 예외 규칙 |

`CLAUDE.local.md`는 커밋하지 않는 개인 메모용으로 쓰고, `.gitignore`에 넣으세요.

---

## 1. 파일 만들기

프로젝트 루트에 `CLAUDE.md`를 만들고 규칙을 적습니다.
빈 화면이 부담되면 Claude Code에서 `/init`을 실행하면 저장소를 훑어 초안을 만들어 줍니다.

---

## 2. 무엇을 적나 — 구성 요소 4가지

### ① 프로젝트 개요
이 프로젝트가 무엇을 위한 것이고 최종 목표가 무엇인지 정의합니다.
목표가 적혀 있어야 AI가 애매한 요청을 목표 방향으로 해석합니다.

### ② 브랜드 보이스 & 톤
답변과 산출물의 어조를 명시합니다. "전문적이고 실용적인", "친근한" 같은 형용사에서
멈추지 말고 **금지 표현**까지 적으면 편차가 확 줄어듭니다.

### ③ 작업 규칙 (SOP)
- 업무 처리 순서
- 파일을 저장하는 폴더 구조
- 결과물 형식 (파일명 규칙, 확장자, 버전 관리)
- 하지 말아야 할 것

가장 효과가 큰 절입니다. **"하지 마라"는 "하라"보다 강하게 작동합니다.**

### ④ 에이전트 역할
리서치 · 콘텐츠 · 디자인 · 검수처럼 여러 에이전트를 굴린다면
각자의 담당 범위와 산출물을 정의해 둡니다. 역할이 겹치면 결과가 서로를 덮어씁니다.

여기서 실제로 품질을 만드는 건 역할 목록이 아니라 **인계 규칙** — 각 에이전트가
무엇을 입력으로 받고, 무엇을 만들면 안 되는지입니다. 자세한 구성은
[docs/agent-pipeline.md](agent-pipeline.md) 참고.

---

## 3. 더 쉽게 적용하는 팁

직접 다 적기 어렵다면, 프로젝트 폴더 안에 브랜드 가이드라인이나 웹사이트 정보가 담긴
이미지·텍스트를 넣어 두고 이렇게 지시하세요.

> "이 자료를 바탕으로 CLAUDE.md를 작성해줘."

이미 쌓인 자료가 규칙의 원본이 되므로, 백지에서 쓰는 것보다 훨씬 정확합니다.

---

## 4. 왜 이렇게 하나

- **토큰 효율화** — 매 작업마다 긴 설명을 다시 입력할 필요가 없습니다.
- **일관성 유지** — 디자인 스타일, 말투, 저장 위치가 매번 같은 기준으로 나옵니다.
- **업무 자동화** — 잘 짜인 `CLAUDE.md`가 있으면 "리서치해줘", "카드뉴스 만들어줘" 같은
  짧은 명령만으로 복잡한 작업이 굴러갑니다.

---

## 5. 잘 굴러가게 유지하는 법

1. **짧게.** 매 세션 컨텍스트에 통째로 들어갑니다. 길수록 개별 규칙의 힘이 약해집니다.
   지키지 않아도 되는 규칙은 지웁니다.
2. **추상어 대신 예시.** "깔끔하게" 대신 `2026-08-21-product-brief.md` 같은 실물 예시를 넣습니다.
3. **어긋날 때마다 갱신.** 결과물이 의도와 다르면 그 자리에서 다시 지시하지 말고
   규칙을 고칩니다. 같은 지적을 두 번 했다면 그건 `CLAUDE.md`에 들어갈 항목입니다.
4. **커밋해서 공유.** 팀이 같은 기준으로 일하게 됩니다.

---

**요약하자면, `CLAUDE.md`는 AI에게 "너는 이런 규칙으로 일하는 사람이야"라고
정체성을 부여하는 과정입니다.**

실제 적용 예시는 이 저장소 루트의 [CLAUDE.md](../CLAUDE.md)를 참고하세요.
